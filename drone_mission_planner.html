    How this planner works

    This tool lets you build an autonomous flight route without touching any code or GPS coordinates by hand, and — if you're on a desktop Chrome/Edge browser with a flight controller plugged in — send it straight to real ArduPilot hardware.

    Plan a mission

    1. Find your location. Type a place name and the map flies there — no manual latitude/longitude entry.
    2. Draw the route. Click on the map to drop waypoints in order. The first click becomes the home / take-off point automatically.
    3. Set altitude & speed. One cruise altitude and speed apply to the whole mission — per-waypoint altitude is adjustable in the list on the left.
    4. Simulate. Press "Simulate" to preview the flight with live telemetry, all in the browser — no hardware needed.

    Connect to a real ArduPilot flight controller

    Section 4 in the side panel talks directly to your flight controller using MAVLink — the same open-source protocol that Mission Planner and QGroundControl use — over the Web Serial API built into Chrome/Edge.

    1. Plug your Pixhawk / other ArduPilot board into this computer over USB.
    2. Pick your vehicle type and baud rate, then click Connect over USB and choose the correct port in the browser prompt.
    3. Once connected (heartbeat detected), click Upload mission to flight controller — this sends your waypoints using the standard MAVLink mission protocol.
    4. Only when you've physically checked the aircraft is safe, tick the safety box and use Arm & start mission, which arms the vehicle and switches it into AUTO mode.

    Notes: Web Serial only works in Chromium browsers, needs a real USB connection, and generally needs to run as a normal page rather than embedded inside another site — if the Connect button doesn't do anything here, download the file and open it directly in Chrome. Always test with propellers off first, keep a manual RC override ready, and follow your local drone regulations.
